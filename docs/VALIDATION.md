# Package validation — 12 October 2026

Validation was performed against the staged package with the existing study
Python environment, without reading the private study data.

- All packaged Python files pass syntax parsing.
- 67 existing selected tests collect successfully, including imports for all
  twelve model families and the diagnostic controls.
- 21 selected tests passed: spatial splitting (5), enriched linear regression
  (3), compact CNN/ResNet (6), and U-Net controls (7).
- The initial linear integration test found missing protocol documents required
  for runtime source archiving. Those dependencies were included, and the failed
  test passed on rerun. The other 20 tests had already passed.
- Synthetic tests cover fitting, selection, masks, georeferenced predictions,
  spatial context, shared controls, checkpointing and report creation at small scale.
- Packaged file hashes are checked against the provenance manifest. Historical
  snapshots retain their source hashes; path-only adaptations record both hashes.
- The ZIP is built from a text-file allowlist, excluding datasets, weights,
  predictions, logs, caches and test-generated bytecode. Credential-pattern checks
  found no matching GitHub token or private-key patterns.

The full 67-test suite was collected, not executed. No clean-environment installation,
full-scale training, original-data reproduction, or figure regeneration was performed.
Rasterio emitted pending-deprecation warnings during synthetic raster creation.
