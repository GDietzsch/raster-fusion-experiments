# Supporting code

Use the numbered folders at the repository root to browse and run the algorithms.

- `raster_fusion_ai/`: shared routines, original command interfaces and synthetic software tests.
- `outputs/` and `work/`: source code for the supplementary analyses reported in the article.
- `provenance/`: historical source snapshots and file hashes.
- `docs/`: archived technical documentation from the original code package; file paths may refer to the earlier layout.

These folders contain code, configuration and documentation only. No study data, fitted weights or prediction rasters are supplied.
